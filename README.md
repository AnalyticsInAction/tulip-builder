# Tulip Builder

A private family page for building a LEGO set together. Everything personal in
this repository (progress, photos and the instruction pages) is encrypted in the
browser before it is stored; it can only be read with the family link.

The 3D build viewer uses part shapes from the LDraw parts library (CC BY 4.0, ldraw.org)
and is drawn with three.js (MIT licence, see vendor/three/LICENSE).
